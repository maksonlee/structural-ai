| Work | Documented practice / existing automation | What this case adds with AI |
|---|---|---|
| Architectural handoff | An attributed Taiwanese practitioner describes starting from architectural drawings and developing structural alternatives. | Organize the simulated requirements and expose missing/interface information. |
| Modelling and calculation | Engineering analysis software already performs numerical calculations. | Help write/review the case converter, prepare explicit assumptions and invoke actual tools. |
