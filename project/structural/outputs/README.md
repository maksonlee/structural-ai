# Structural engineer's outputs

Open [the output index](current.md) for the report, drawings and reinforcement
example that accompany the article.

`deliverables/` contains the reader-facing results and supporting check data.
`runs/` contains generated models, command logs and raw numerical evidence,
ignored by version control. Readers can use the reports without opening it;
regenerating drawings and the landing calculation requires verified analysis
evidence. See the [reproduction instructions](../../../docs/development.md).
