# Calculations behind the article

`checklist.yaml` shows engineering coverage, including unfinished stages.
It does not define whether the introductory article can be drafted.

The current example uses `core-interface-loads.yaml` for labelled synthetic
panel/lift/roof inputs. `wall-interface-basis.yaml`, the interface checks and audit
document the adopted wall/frame correction. `coordination-checks.yaml`
records the current dimensional screens.

`stair-load-method.md` explains the source-derived released-strip load path
and its limitations.

`landing-strip.yaml` holds the article's new local reinforcement selections.
Its [worked calculation and drawing](../outputs/deliverables/landing-strip.md)
derive geometry and loads from the existing building. Selected gravity strength,
minimum steel and spacing are checked; whole-landing, anchorage, seismic and
serviceability design remain NOT_CHECKED. There is no complete RC or foundation
design package here.
